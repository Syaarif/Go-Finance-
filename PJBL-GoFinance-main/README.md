# 💰 Go Finance

Aplikasi mobile manajemen keuangan pribadi berbasis Flutter untuk **Android** dan **iOS**. Dibuat sebagai proyek PJBL kelas 11 SMKN 8 Semarang.

## 📱 Fitur

- Splash Screen & Onboarding interaktif
- Login & Registrasi akun dengan validasi form
- Kalender Tagihan & Pengingat Lokal Terjadwal (H-7 & H-1)
- Profil & Pengaturan Akun (Edit Profil, Keamanan, Preferensi, Notifikasi)
- Bottom Navigation Bar (Beranda, Transaksi, Scan, Tabungan, Tagihan)

## 🚀 Cara Jalankan

```bash
flutter pub get
flutter run
```

Build APK Android:

```bash
flutter build apk --release
```

Build iOS (di macOS):

```bash
flutter build ios --release
```
