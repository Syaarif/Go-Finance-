## 📱 Fitur

- Splash Screen & Onboarding
- Login & Registrasi akun
- Animasi halus dan tampilan modern

## 🛠️ Teknologi

- **Flutter** — framework utama
- **Dart** — bahasa pemrograman
- **Flutter Web** — build untuk browser

## 🚀 Cara Jalankan

```bash
flutter pub get
flutter run
```

Untuk web:

```bash
flutter build web --release
```
